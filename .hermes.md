# local-search-service — Local Search/Crawl/Index Service

HTTP search API that crawls, indexes, and serves documents locally. Docker service with `docker-compose.yml`.

## Layout

```
crawl_extract.py       # Site crawling + content extraction
indexer.py             # Document indexing
search_api.py          # HTTP search endpoint
external_adapter.py    # External data source adapter
seeds.txt              # Seed URLs to crawl
docs.jsonl             # Pre-captured document content for testing
tests/                 # Unit test suite
```

## Conventions

- This is a standalone microservice — keep it self-contained.
- All output stays within this directory, never in ~/home or workspace root.
- Dockerfile and docker-compose.yml define the full service; dependencies go through `requirements.txt`.
